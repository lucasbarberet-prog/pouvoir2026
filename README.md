# Pouvoir 2026

Simulation géopolitique : dirigez un pays, négociez, gérez l'économie, la sécurité et les crises.

**Jouer :** https://lucasbarberet-prog.github.io/pouvoir2026/

## IA gratuite intégrée

L'IA du jeu (chats, ordres, grèves, articles) tourne **dans votre appareil** grâce à WebLLM et au modèle libre Qwen 2.5 :
aucun abonnement, aucun service extérieur. Au premier lancement, le modèle est téléchargé une seule fois
(environ 0,4 Go sur téléphone, 1 Go sur ordinateur), de préférence en wifi.

Navigateurs compatibles (WebGPU) : Chrome ou Edge récents sur ordinateur et Android, Safari à jour sur iPhone (iOS 26 ou plus).
Sur un navigateur incompatible, le jeu fonctionne sans IA.

Réglages : `js/config.js`.
